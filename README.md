# .github

Organization-level GitHub configuration for [Vibewatch](https://vibewatch.io).

- [`profile/README.md`](profile/README.md) renders as the public org profile at [github.com/Vibewatch-io](https://github.com/Vibewatch-io).
- [`profile/assets/`](profile/assets/) holds the brand assets used by that profile (logo lockups + symbol).

Brand source of truth lives in the internal `vibewatch-docs` repo (`brand/STYLE_GUIDE.md`). Keep the palette, wordmark, and tone here in sync with it.
